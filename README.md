# ✍️ 블로그 챌린지 관리 앱

블로그 글쓰기 챌린지를 운영하기 위한 웹앱입니다.
관리자는 **Google 계정**으로 로그인합니다. 관리자가 아이디와 비밀번호를 만들어 챌린지원에게 전달하면, 챌린지원은 그 아이디로 로그인해 블로그 글을 등록하고 진척 상황을 확인합니다.

- 구조: [독서 챌린지 인증 시스템](https://github.com/philosophyAIEDU/260818comingssoni)과 같이 **빌드 도구 없는 정적 HTML/CSS/JS**와 **Firebase(Firestore)**로 만들었습니다.
- **Firebase 무료 요금제(Spark)**에서 무료로 쓸 수 있는 **Authentication(Google, 이메일/비밀번호)**과 **Cloud Firestore**만 사용합니다. Cloud Functions와 Storage는 쓰지 않습니다.
- **Vercel**에 그대로 배포할 수 있습니다. 서버 코드는 `api/` 폴더의 서버리스 함수 2개뿐입니다.

## 기능

### 로그인 (`index.html`)
- **챌린지원**: 관리자가 정해 준 **아이디(한글 가능)와 비밀번호**로 로그인합니다.
- **관리자**: 아래쪽 **관리자 로그인 (Google)** 버튼으로 로그인합니다. 관리자로 지정된 Google 계정(`hyj901009@gmail.com`)만 관리자 페이지에 들어갈 수 있고, 다른 Google 계정은 거부됩니다.

### 관리자 페이지 (`admin.html`)
| 탭 | 기능 |
| --- | --- |
| 📈 **진척 현황** | 기준일을 기준으로 챌린지원별 **순위**(기간 포스팅 개수), **위클리**와 **챌린지 목표** 달성 현황, 목표 진행률, 검토 대기 수를 보여 줍니다. 아래 **기간별 매트릭스**는 일별과 주별로 바꿔 볼 수 있습니다. |
| 📝 **포스팅 검토** | 제출된 글을 **검토 후 등록**과 **자유 등록**으로 나눠 보여 줍니다. 상태(검토 대기, 검토 완료, 수정 요청), 챌린지원, 검색어로 거를 수 있습니다. 검토 요청 글에는 ✅ 검토 완료, ✏️ 수정 요청을 누를 수 있습니다. 모든 글 아래에 **500자 이내 코멘트**를 달고 수정하거나 지울 수 있습니다. 챌린지원이 코멘트를 읽었는지, 어떤 반응(👍❤️👏🙏🔥)을 남겼는지도 보입니다. |
| 👀 **방문자 추이** | 챌린지원 블로그의 **일 방문자 수**를 **챌린지 기간 전체** 선 그래프로 보여 줍니다. 아직 오지 않은 날은 비워 두고 하루하루 채워지며, 점에 마우스를 올리면 그날의 방문자 수가 보입니다. 네이버 블로그는 **자동으로 가져오고**(아래 참고), 그 밖의 블로그는 챌린지원이 입력한 값입니다. **이 기수 전체 네이버에서 가져오기** 버튼과 사람별 🔄 버튼으로 바로 갱신할 수도 있습니다. 전체 합계나 한 사람씩 골라 볼 수 있습니다. 요약 칸에는 **현재 일방문자수**, 평균, 최고 값이 나오고, 챌린지원별 표에도 같은 값이 나옵니다. |
| 👥 **챌린지원 관리** | 아이디와 비밀번호를 정해 계정을 만듭니다. 비밀번호는 **숫자 4자리**(4자 이상)로 정할 수 있고, [자동 생성]을 누르면 숫자 4자리가 만들어집니다. 여러 명을 한 번에 만들 수도 있습니다. 계정을 만들면 **전달용 안내문**(주소, 아이디, 비밀번호)이 생성되며, 복사해서 카톡 등으로 보내면 됩니다. 이름과 블로그 주소 수정, 기수 이동, 삭제도 이 탭에서 합니다. **비밀번호 재설정**은 서버 설정이 필요합니다(아래 참고). |
| ⚙️ **기수 · 미션 설정** | 미션 **기간(시작일~종료일)**과 **위클리 목표(개/주)**, **챌린지 목표(기간 전체 개수)**를 정합니다. **새 기수 시작**을 누르면 새 기수가 만들어져 진척이 0부터 다시 집계되고, 원하면 기존 챌린지원을 계정 그대로 새 기수로 옮길 수 있습니다. 이전 기수 기록은 상단의 기수 선택에서 계속 볼 수 있습니다. 기록을 아예 지우려면 **기수 데이터 초기화**를 씁니다. |

### 챌린지원 대시보드 (`member.html`)
- **미션 진척**: 위클리와 챌린지 목표 진행 막대를 보여 줍니다. **날짜별 기록** 칸에는 날짜가 MM/DD로 적혀 있고, 주차별 상세도 볼 수 있습니다.
- **🏆 챌린지 순위**: 같은 기수 챌린지원끼리 **챌린지 기간 포스팅 개수**로 순위를 매깁니다(동점은 같은 등수). 다른 사람의 글 내용은 보이지 않고 이름과 개수만 나옵니다. 서버가 5분마다 다시 세고, 내 개수는 등록하는 즉시 반영됩니다.
- **블로그 글 등록**: 📝 **검토 요청**(관리자가 검토)과 🚀 **자유 등록**(바로 기록) 중에서 고릅니다. URL, 제목, 발행일을 적고, 검토 요청일 때만 관리자에게 남길 메모를 적습니다. 발행일은 미션 기간 안에서만 고를 수 있습니다. 검토가 끝나지 않은 글은 수정하거나 삭제할 수 있습니다.
- **받은 코멘트 뷰어**: 새 코멘트에는 NEW 표시가 붙습니다. 👍 따봉, ❤️ 하트, 👏, 🙏, 🔥 중 하나를 누르거나 ✔ 확인을 누르면 **읽음** 처리되고, 고른 반응은 관리자 화면에 보입니다.
- **방문자 수 추이**: 관리자가 등록한 블로그 주소가 네이버 블로그이면 방문자 수를 자동으로 가져옵니다. **🔄 네이버에서 가져오기** 버튼으로 바로 갱신할 수도 있습니다. 블로그 주소는 챌린지원이 바꿀 수 없습니다. 네이버가 아닌 블로그는 **직접 입력하기**로 날짜별로 입력합니다.
- 비밀번호는 챌린지원이 바꿀 수 없습니다. 바꾸려면 관리자가 **챌린지원 관리 → 비번 재설정**으로 바꿔 줍니다.

### 집계 규칙
- 미션 기간 안에 **발행일(postDate)**이 들어가는 글만 진척에 반영합니다.
- **위클리**: 월요일부터 일요일까지 올린 글 수입니다. 기간에 일부만 걸친 주는 걸친 날 수만큼 목표를 줄여서 비교합니다(올림). 예를 들어 주 5개 목표에 기간이 5일만 걸치면 목표는 4개입니다.
- **챌린지 목표**: 챌린지 기간 전체 동안 올린 글 수입니다. 예전에 만든 기수의 먼슬리 목표 값은 챌린지 목표로 이어서 씁니다.
- **연속 포스팅**: 글을 1개 이상 올린 날이 며칠 이어졌는지 셉니다. 오늘 아직 안 썼으면 어제까지로 셉니다.
- **순위**: 챌린지 기간 포스팅 개수가 많은 순입니다. 정확히 세려면 Firestore에 `posts` 복합 색인(`uid`, `cohortId`, `postDate`)이 있어야 합니다. 이 색인이 없으면 기간 조건 없이 그 기수의 글을 모두 셉니다. 발행일을 기간 안에서만 고를 수 있으므로 보통은 결과가 같습니다. 색인 설정은 [`firestore.indexes.json`](firestore.indexes.json)에 있습니다.
- 검토 요청 글은 **검토 대기 상태여도 미션으로 집계**됩니다. 검토 상태는 글 품질에 대한 피드백 용도입니다.

### 네이버 블로그 방문자 수 자동 가져오기
- 네이버는 방문자 수 **공식 API가 없습니다**. 그래서 블로그 방문자 위젯이 쓰는 **비공식 주소**(`blog.naver.com/NVisitorgp4Ajax.nhn?blogId=…`)에서 최근 5일치를 읽어 옵니다. 브라우저에서는 이 주소를 직접 부를 수 없어서 Vercel 서버 함수(`api/naver-visitors.js`)가 대신 가져와 저장합니다.
- 가져오는 때:
  1. **매일 00:10(한국 시간) 자동 실행**(Vercel Cron) — 전날 방문자 수가 확정된 직후입니다. 한 번에 5일치를 받으므로 며칠 빠져도 메워집니다.
  2. 챌린지원이 대시보드를 열 때 하루 한 번 자동으로 가져옵니다.
  3. 화면의 **🔄 버튼**으로 즉시 가져옵니다.
- 조건:
  - 관리자가 **챌린지원 관리** 탭에서 등록한 **블로그 주소가 네이버 블로그**여야 합니다(계정을 만들 때 넣거나 [수정]으로 추가). `blog.naver.com/아이디`, `m.blog.naver.com/아이디`, `아이디.blog.me` 모두 인식합니다.
  - 블로그의 **방문자 수가 공개**되어 있어야 합니다.
  - Vercel에 `FIREBASE_SERVICE_ACCOUNT`와 `CRON_SECRET`이 등록되어 있어야 합니다.
- ⚠️ 비공식 방식이라 **네이버가 이 주소를 바꾸면 자동 수집이 멈출 수 있습니다.** 그래도 직접 입력은 계속 쓸 수 있습니다. 같은 날짜에는 마지막으로 저장된 값이 남습니다. 네이버 블로그라면 자동 수집 값이 매일 덮어씁니다.

## 처음 설정하기

### 1. Firebase 프로젝트 만들기 (Spark 무료 요금제)
1. [Firebase 콘솔](https://console.firebase.google.com/)에서 프로젝트를 만듭니다.
2. **Authentication → 로그인 방법**에서 **Google**(관리자용)과 **이메일/비밀번호**(챌린지원용)를 모두 **사용 설정**합니다.
   - 같은 화면의 **설정 → 사용자 작업**에서 "계정 생성(가입) 허용"은 **켜 둔 상태로 유지**해야 합니다. 관리자가 브라우저에서 챌린지원 계정을 만들기 때문입니다. 낯선 사람이 가입해도 관리자가 등록하지 않은 계정은 보안 규칙 때문에 아무 데이터도 보지 못합니다.
3. **Firestore Database → 데이터베이스 만들기**를 누릅니다. 위치는 `asia-northeast3 (서울)`을 권장하고, 프로덕션 모드로 시작합니다.
4. **Firestore → 규칙** 탭에 이 저장소의 [`firestore.rules`](firestore.rules) 내용을 그대로 붙여 넣고 **게시**합니다. ⚠️ 이 단계를 빠뜨리면 아무것도 저장되지 않습니다.
5. **프로젝트 설정 → 일반 → 내 앱 → 웹 앱(</>) 추가**를 누르고, 나오는 `firebaseConfig` 값을 적어 둡니다.

### 2. Vercel에 배포하기
1. 이 저장소를 Vercel에서 **Import**합니다. Framework Preset은 `Other`로 두고, Build Command와 Output Directory는 비워 둡니다.
2. **Settings → Environment Variables**에 아래 값을 넣습니다.

   | 이름 | 값 | 필수 |
   | --- | --- | --- |
   | `FIREBASE_API_KEY` | firebaseConfig.apiKey | ✅ |
   | `FIREBASE_AUTH_DOMAIN` | firebaseConfig.authDomain | ✅ |
   | `FIREBASE_PROJECT_ID` | firebaseConfig.projectId | ✅ |
   | `FIREBASE_APP_ID` | firebaseConfig.appId | ✅ |
   | `FIREBASE_MESSAGING_SENDER_ID` | firebaseConfig.messagingSenderId | |
   | `FIREBASE_STORAGE_BUCKET` | firebaseConfig.storageBucket | |
   | `FIREBASE_SERVICE_ACCOUNT` | 서비스 계정 키 JSON 전체 (아래 참고) | 권장 |
   | `CRON_SECRET` | 아무도 모르는 긴 임의 문자열 (예: 비밀번호 생성기로 32자) | 권장 |

   > 환경변수 대신 [`js/config.js`](js/config.js)의 `FIREBASE_CONFIG`에 값을 직접 적어도 됩니다. 웹 앱 설정값은 원래 브라우저에 공개되는 값이라 커밋해도 괜찮습니다.
3. Firebase 콘솔 **Authentication → 설정 → 승인된 도메인**에 Vercel 주소(예: `xxx.vercel.app`)를 추가합니다. 이게 없으면 Google 로그인 창이 뜨지 않습니다.
4. 사이트에 들어가 **관리자 로그인 (Google)**으로 로그인합니다.
5. 관리자 페이지의 **기수 · 미션 설정**에서 첫 기수(예: 1기)와 기간, 목표를 정합니다.
6. **챌린지원 관리**에서 계정을 만들고, 생성된 안내문을 챌린지원에게 전달합니다.

### 3. (권장) 서버 기능 켜기: 네이버 방문자 수 자동 수집, 순위, 비밀번호 재설정, 계정 완전 삭제
아래 기능은 브라우저만으로는 할 수 없어서 Vercel 서버리스 함수에서 처리합니다.
- 네이버 방문자 수 수집: `api/naver-visitors.js`
- 다른 사람의 비밀번호 재설정과 계정 삭제: `api/admin-users.js`
- 챌린지원 순위: `api/leaderboard.js`

Admin SDK의 계정 관리 기능은 **Spark 요금제에서도 무료**입니다.

1. Firebase 콘솔 → **프로젝트 설정 → 서비스 계정 → 새 비공개 키 생성**을 눌러 JSON 파일을 받습니다.
2. 파일 내용 전체를 Vercel 환경변수 `FIREBASE_SERVICE_ACCOUNT`(Secret)에 붙여 넣습니다.
3. Vercel 환경변수 `CRON_SECRET`(Secret)에 긴 임의 문자열을 넣습니다. Vercel이 매일 예약 실행할 때 이 값을 함께 보내서, 다른 사람이 수집 주소를 함부로 호출하지 못하게 막습니다.
4. **다시 배포(Redeploy)**합니다. 예약 실행은 Vercel 프로젝트의 **Settings → Cron Jobs**에서 확인할 수 있습니다(Hobby 무료 플랜은 하루 1회까지 가능).
   - 키를 세 개로 나눠 넣는 방식도 됩니다: `FIREBASE_PROJECT_ID`, `FIREBASE_CLIENT_EMAIL`, `FIREBASE_PRIVATE_KEY`
   - ⚠️ 이 키 파일은 **절대 저장소에 커밋하지 마세요.**

설정하지 않아도 나머지 기능은 모두 동작합니다. 이때 챌린지원 삭제는 앱의 데이터만 지우며, 같은 아이디를 다시 쓰려면 Firebase 콘솔 Authentication에서 계정도 지워야 합니다. 비밀번호 재설정과 순위도 이 설정이 있어야 동작합니다.

## 무료 한도 안에서 쓰기
Spark 요금제의 Firestore 무료 한도는 하루 **읽기 5만, 쓰기 2만, 삭제 2만**이고 저장 용량은 1GiB입니다.
- 챌린지원 대시보드를 한 번 열 때 읽기는 대략 "내 글 수 + 받은 코멘트 수 + 방문자 기록 수 + 몇 건"입니다.
- 관리자 페이지를 한 번 열면(또는 ↻를 누르면) 보고 있는 기수의 글, 코멘트, 방문자 기록과 전체 멤버를 한 번씩 읽습니다.
- 실시간 리스너를 쓰지 않고 필요할 때만 읽기 때문에, 수십 명 규모의 챌린지라면 한도에 한참 못 미칩니다.
- 복합 색인이 필요한 쿼리를 쓰지 않아서 **색인을 따로 만들 필요가 없습니다.**

## 보안 메모
- **4자리 비밀번호**: Firebase는 6자 미만 비밀번호를 받지 않습니다. 그래서 4~5자 비밀번호는 앱이 정해진 글자를 덧붙여 늘린 뒤 Firebase에 보냅니다(`js/utils.js`의 `toAuthPassword`). 6자 이상 비밀번호는 그대로 쓰므로 예전 계정도 그대로 로그인됩니다. 4자리 숫자는 경우의 수가 1만 개뿐입니다. Firebase가 같은 계정에 로그인 실패가 반복되면 잠시 막아 주지만, 더 안전하게 하려면 6자 이상을 쓰세요.
- **관리자 변경·추가**: [`js/config.js`](js/config.js)의 `adminEmails`와 [`firestore.rules`](firestore.rules)의 `isAdmin()` 목록을 **둘 다** 고친 뒤, 규칙을 Firebase 콘솔에 다시 게시합니다. 실제 권한은 보안 규칙이 정하고, 화면과 서버 API는 `config.js` 목록을 봅니다.
- 관리자 판별은 "Google로 로그인했고, 이메일이 인증되었고, 목록에 있는 이메일"일 때만 통과합니다. 같은 이메일로 비밀번호 계정을 만들어도 관리자가 될 수 없습니다.
- 한글 아이디는 SHA-256 해시를 거쳐 `u<해시>@challenge.example.com` 형태의 **내부용 계정**으로 바뀝니다. 실제 메일은 가지 않습니다. 이 도메인(`APP.idEmailDomain`)을 운영 중에 바꾸면 기존 계정으로 로그인할 수 없게 됩니다.
- 접근 제어는 [`firestore.rules`](firestore.rules)가 맡습니다.
  - **관리자**: 목록에 있는 Google 계정입니다. 모든 데이터를 읽고 쓸 수 있습니다.
  - **챌린지원**: 자기 글, 받은 코멘트, 자기 방문자 기록만 읽습니다. 코멘트에는 "확인/반응" 필드만 바꿀 수 있습니다. 검토 완료된 글은 수정하거나 삭제할 수 없습니다.
  - 그 밖의 로그인 계정은 아무 데이터에도 접근할 수 없습니다.

## 파일 구조
```
index.html            로그인 (챌린지원 아이디/비밀번호, 관리자 Google)
member.html           챌린지원 대시보드
admin.html            관리자 페이지
css/style.css         공통 스타일 (라이트/다크)
js/config.js          설정 (Firebase 설정, 반응 이모지, 기본 목표 등)
js/utils.js           날짜·진척 계산 (순수 함수, 테스트 대상)
js/firebase.js        Firebase 인증 + Firestore 데이터 계층
js/ui.js              화면 공통 도우미 (토스트, 진행 막대, SVG 그래프, 접근 제어)
js/login.js | member.js | admin.js   페이지별 스크립트
api/firebase-config.js   Vercel 환경변수 → 웹 앱 설정 전달
api/admin-users.js       비밀번호 재설정 / 계정 삭제
api/naver-visitors.js    네이버 블로그 방문자 수 수집 (버튼 + 매일 예약 실행)
api/leaderboard.js       챌린지 순위 (기수별 포스팅 개수, 5분 캐시)
firestore.rules       Firestore 보안 규칙
test/utils.test.js    진척 계산 단위 테스트
```

## 로컬 개발
```bash
npm test                 # 진척 계산 단위 테스트
npm run serve            # 정적 서버 http://localhost:3000 (js/config.js에 Firebase 설정 필요)
npx vercel dev           # /api 함수까지 함께 실행 (Vercel 환경변수 사용)
```

실제 Firebase 프로젝트 없이 **에뮬레이터**로 시험해 볼 수도 있습니다(Java 필요).
```bash
npm run emulators        # Auth(9099) + Firestore(8080), firestore.rules가 적용됩니다
npm run serve            # 다른 터미널에서 실행
# 브라우저에서 http://localhost:3000/?emulator=1 로 접속
# (에뮬레이터의 Google 로그인 창에서 hyj901009@gmail.com 으로 가짜 계정을 만들면 관리자로 들어갑니다)
```
